# Discourse Embed Markdown Plugin

**Plugin Summary**

A Discourse plugin that converts embedded topic content to Markdown, enabling rich Onebox previews. It also provides a customizable template for the first post of embedded topics.

## Features

- **Markdown Conversion:** Automatically converts raw HTML embeds to Markdown.
- **Onebox Support:** Enables automatic Onebox generation for embedded URLs.
- **Custom Templates:** Set a custom first-post template via Admin Settings.
- **Auto-Updates:** Automatically updates existing embedded topics in the background when the template is changed.
